# Сценарий: ревью MR по просьбе из Mattermost

Человек просит «сделай ревью MR» и даёт ссылку на пост в Mattermost (или сразу на MR). Итог ревью
видят в двух местах: треды с замечаниями в GitLab и реакция на пост в Mattermost.

## 1. Прочитать пост

```
fsh mm thread <permalink>
```

В посте ссылки на MR и задачи. MR несколько — каждый проходит шаги 2–4, реакция одна на весь пост.

## 2. Собрать контекст

```
fsh mr <номер>
fsh mr-comments <номер>
fsh jira <KEY>
```

Задача Jira нужна, чтобы сверить MR с требованием, а не только с правилами. Открытые треды бота и
коллег прочитай: то же замечание второй раз не пишется.

## 3. Ревью

Дифф — только коммиты MR против merge-base с целевой веткой (после мержа dev в ветку
`origin/dev...<ветка>` тянет чужие файлы). Ревью делаешь сам по правилам проекта: скилл ревью MR
проекта, если он есть, иначе `fsh review <номер>` без `--post`, и его находки перепроверяешь по коду.

Замечание остаётся, только если видно в коде, есть файл и строка и понятно, что сломается.
Догадки, вкусовщина и то, что правила проекта предписывают делать именно так, — выбрасываются.

## 4. Треды в GitLab

Каждое замечание — отдельный тред на строке диффа (DiffNote), с префиксом severity:
`BLOCKER`, `WARNING`, `NIT`, вопрос автору — `q:`. Позиция — `base_sha`, `start_sha`, `head_sha`
из `diff_refs` MR. `glab api` с `--input` в некоторых репозиториях закрыт хуком, поэтому
позиция уходит JSON-полем:

```
glab api -X POST projects/<id>/merge_requests/<iid>/discussions \
  -f "body=<текст>" \
  -F 'position={"position_type":"text","base_sha":"…","start_sha":"…","head_sha":"…","old_path":"<файл>","new_path":"<файл>","new_line":<строка>}'
```

Текст — обычным языком, без хешей коммитов и id тредов. Approve и мерж не ставишь.

## 5. Реакция на пост

```
fsh mm react <permalink> ✅   # замечаний нет
fsh mm react <permalink> 👀   # оставлен хотя бы один тред
```

Реакция ставится на тот пост, ссылку на который дал человек. Текстом в тред Mattermost не пишешь,
если не попросили.

## 6. Отчёт человеку

Коротко: какой MR, что нашёл (или «замечаний нет»), ссылки на треды, какая реакция стоит.
