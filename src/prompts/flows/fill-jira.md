# Сценарий: обязательные поля Jira

Два поля задачи обязательны: **Technical details for QA** и **Контент**. Без них задачу не примут,
а переход по статусу завернёт валидатор.

## 1. Technical details for QA

Текст пишет скилл проекта `manual-qa`: инструкция для ручного тестировщика по коммитам ветки и
контексту сессии. Вызови скилл, сохрани результат в файл и положи его в поле:

```
fsh jira field FD-XXXX "Technical details for QA" --file qa.md
```

`--file` обязателен: инструкция многострочная, в аргументах командной строки она теряет переводы
строк. Вместо пути можно передать `-` и подать текст на stdin.

## 2. Контент

Сюда идёт то, что должен завести контент-менеджер: новые строки словаря и фича-флаги.

**Словарь.** Формат из правил проекта (`.claude/rules/dict.md`): ровно три колонки, шапка
обязательна, одна строка на ключ, значения не в кавычках.

```
Группа, Ключ, Значение
checkout, trial_already_used_notice, Пробный период уже использован
```

Ключи бери из своего же диффа — те, что появились в коде и которых нет в словаре. Скилл
`add-dictionary-translations` заводит их на дев-стенде, чтобы проверить вёрстку; на прод они
попадают только этим текстом в задаче.

**Фича-флаги.** Что уже есть и в каком состоянии:

```
fsh growthbook list
fsh growthbook get имя-флага
```

Новый флаг задачи заводится выключенным, включает его релиз-менеджер:

```
fsh growthbook create имя-флага off
```

В поле напиши имя флага, что он включает и в каком окружении проверять.

Собери обе части в один файл и запиши:

```
fsh jira field FD-XXXX "Контент" --file content.txt
```

Ни новых ключей, ни флагов в задаче нет — так и напиши одной строкой. Пустое поле хуже короткого
ответа: оно заворачивает переход по статусу.

## 3. Проверить

```
fsh jira FD-XXXX
```

Команда `fsh jira field` перечитывает задачу после записи и падает, если поле осталось пустым, но
глазами посмотреть дешевле, чем потом объясняться с QA.

## Если имя поля не совпало

`fsh jira field` с незнакомым именем отвечает списком правимых полей именно этой задачи — возьми
имя оттуда. Набор полей у типов задач разный, угадывать не надо.
