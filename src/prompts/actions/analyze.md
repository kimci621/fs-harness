## Что от тебя нужно

1. **О чём задача на самом деле.** Одним абзацем, своими словами. Если постановка допускает два прочтения — скажи какие.
2. **Где в коде.** Конкретные файлы и функции. Ищи по именам сущностей из задачи (компонент, поле, эндпоинт, строка интерфейса), а не по общим фразам: поиск прозой в чужом коде не работает. Если есть `graphify query` — пользуйся им именем сущности. Не нашёл — скажи честно, где искал.

4. **Что сломается.** Кто ещё пользуется тем, что ты собрался менять. Общие компоненты, стора, типы, тесты.
5. **Вопросы к постановщику.** Только те, без ответа на которые задачу нельзя закрыть правильно. Нет таких — так и скажи, не выдумывай.
